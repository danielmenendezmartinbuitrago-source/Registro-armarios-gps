# Registro de armarios eléctricos GPS · Versión 3.3

Aplicación web progresiva para registrar armarios eléctricos, posición GPS y fotografías localmente.

En la primera conexión, selecciona la carpeta raíz **ARMARIOS ELECTRICOS**. La aplicación crea automáticamente `REGISTROS`, el catálogo, el archivo JSON y las carpetas fotográficas por prefijo, incluido `F41`.

Consulta `LEEME.txt` para los cambios de las versiones 3.2 y 3.3, estructura local y publicación en GitHub Pages.


En la versión 3.3, al completar correctamente el alta se muestra una confirmación con la referencia registrada (por ejemplo, «Armario F03-01-25 registrado.»). Si falla el guardado, no se muestra la confirmación de éxito.
