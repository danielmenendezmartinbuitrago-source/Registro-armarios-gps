# Registro de armarios eléctricos GPS · Versión 3.1

Aplicación web progresiva para registrar armarios eléctricos, posición GPS y fotografías localmente.

En la primera conexión, selecciona la carpeta raíz **ARMARIOS ELECTRICOS**. La aplicación crea automáticamente `REGISTROS`, el catálogo, el archivo JSON y las carpetas fotográficas por prefijo, incluido `F41`.

Consulta `LEEME.txt` para los cambios de la versión 3.1, estructura local y publicación en GitHub Pages.
